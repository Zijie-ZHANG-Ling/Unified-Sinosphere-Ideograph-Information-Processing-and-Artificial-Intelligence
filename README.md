# Unified Sinosphere Ideograph Information Processing and Artificial Intelligence

# 統一漢字文化圈表意文字信息處理與人工智慧

**以漢字文化圈表意文字為中心的信息處理與人工智慧**

*Sinospheric Ideograph-Centered Information Processing and Artificial Intelligence*

## 項目緣起

漢字文化圈擁有源遠流長、獨具特色的表意文字體系，包括漢字、字喃、方塊壯字等。這些文字跨越古今、地域與語言，在長期的歷史發展中形成了豐富而獨特的文字結構、語義體系與文化傳統。

然而，長期以來，漢字文化圈表意文字的信息處理與人工智慧技術，往往以歐美語言文字的信息處理方法及人工智慧技術為主要參考，將主要針對表音文字發展起來的技術範式直接應用於表意文字，卻忽略了漢字文化圈表意文字本身所具有的獨特性，以及這些獨特性為信息處理與人工智慧帶來的巨大優勢。

**漢字文化圈表意文字不應只是現有信息處理與人工智慧技術的適配對象，而應成為信息處理與人工智慧技術自身的出發點。**

我們應當從漢字文化圈表意文字自身的特點出發，探索、發展和建立適合其文字結構、語義體系與文化傳統的信息處理與人工智慧技術。

## 核心思想

### 一、全量表意字符詞表：讓每一個表意文字都有自己的位置

在當今大規模人工智慧模型中，詞表（Vocabulary）規模達到十萬乃至數十萬個 Token 已十分常見。

而 Unicode 所收錄的 CJK 統一漢字及其擴展字符，連同康熙部首等相關字符，總規模不過十萬多個，完全處於當代大規模人工智慧模型詞表可以容納的範圍內。

這意味著，我們完全可以構建以漢字文化圈表意文字為中心的人工智慧模型詞表，**將 Unicode CJK 及相關表意文字字符完整納入詞表，讓每一個表意文字字符都擁有獨立的 Token 表示。**

不必因為一個漢字生僻，就將它切分為與其文字結構和語義無關的 Byte 碎片；也不必因為現有分詞算法的局限，而犧牲表意文字字符本身的完整性。

**完整的表意字符覆蓋，應當成為漢字文化圈表意文字人工智慧的基礎。**

### 二、以字為本：尊重漢字作為語素的天然優勢

歐美語言文字的信息處理，往往需要通過分詞（Tokenization）確定語言處理的基本單位。

對於以字母為基礎的表音文字，單個字母通常不直接承載獨立的詞彙語義，而單詞內部的語素劃分又常常存在複雜性與爭議。因此，從傳統的詞級分詞到 BPE、WordPiece 等子詞分詞方法，逐漸形成了以詞或統計子詞片段為基本處理單位的技術路線。

然而，漢字文化圈表意文字具有完全不同的特點。

**絕大多數漢字本身就可以作為語素，並且在不同時代、不同地域、不同語境中，保持高度相關的語義。**

例如：

- **學校**：其中的「學」表示學習、學問。
- **學習**：其中的「學」同樣表示學習。
- **學而時習之**：其中的「學」依然承載與學習密切相關的語義。

從古代文言到現代漢語，從不同地域的漢字使用傳統到漢字文化圈的其他語言，「學」始終是一個具有高度語義連續性的文字單位。

這正是漢字文化圈表意文字的獨特優勢：**一個字符本身就可以成為橫跨古今、地域與語言的穩定語義錨點。**

然而，當我們直接沿用以詞或子詞為基本單位的分詞方式，將「學校」「學習」等整體編碼為不同 Token 時，共享的「學」便被包裹在不同 Token 內部。

模型將這些 Token 作為獨立的原子單位處理，原本可以直接共享的語素信息被隱藏，跨詞語、跨語境乃至跨時代的文字語義關聯也因此受到阻隔。

這種處理方式，忽略了漢字自身已經提供的天然語義結構。

**我們主張以字為本，將表意文字字符作為信息處理與人工智慧模型的基礎單位，充分發揮字符本身作為語素和語義錨點的價值。**

詞語、短語與更高層次的語義結構，應當建立在字符及其關係之上，而不是以犧牲字符自身的語義完整性為代價。

### 三、以形載義：利用表意文字內部的結構信息

將十萬多個表意文字字符全部納入模型詞表，也引出一個值得重視的問題：不同字符在實際語料中的出現頻率差異巨大，一些生僻字的訓練數據十分有限。

但漢字文化圈表意文字恰恰擁有解決這一問題的獨特條件。

**表意文字不僅字符本身具有意義，其內部構形同樣承載著豐富的信息。**

漢字中的形聲字具有形旁與聲旁，其他大量漢字也具有可以分析的部件和構形關係。這些內部結構反映了文字在形、音、義等方面的聯繫。

例如：

**湔 → ⿰氵前**

這一表意文字描述序列（Ideographic Description Sequence，IDS）表達了「湔」字的左右構形，以及其組成部件「氵」和「前」。

相較於將生僻字直接切分為 Byte，IDS 能夠保留文字自身的構形信息，並建立字符與其組成部件之間的聯繫。

漢字文化圈的文字研究者與開源社群長期積累和維護了大量表意文字描述序列及相關資料。這些成果為構建表意文字中心的信息處理與人工智慧提供了重要基礎。

我們可以進一步利用 IDS、部件、形旁、聲旁等信息，建立具有文字結構意識的字符表示與嵌入向量，使生僻字符也能通過與其他字符共享的部件及構形關係獲得有效的信息表示。

**文字的內部結構不應在 Tokenization 過程中丟失，而應成為人工智慧理解和處理表意文字的重要信息來源。**

從完整字符到內部部件，從字形結構到語義關聯，漢字文化圈表意文字本身就為人工智慧提供了一套豐富的、多層次的信息結構。

### 四、從文字自身出發，而非照搬既有範式

現代人工智慧中的許多信息處理方法，最初是圍繞歐美語言文字的特點發展起來的。

以字母、單詞、子詞為基礎的 Tokenization，以及隨之而來的詞表外字符、Unknown Token、BPE、WordPiece、Byte-level Tokenization 等問題與解決方案，都有其特定的文字系統背景。

漢字文化圈表意文字則具有另一套天然優勢：

- **字符數量有限且可控**：十萬多個表意字符可以完整納入當代大規模模型詞表。
- **字符本身承載語素信息**：大量字符具有直接、穩定且可以共享的語義。
- **跨越古今地域的語義連續性**：同一字符能夠聯繫不同歷史時期、地域與語言的文字使用。
- **豐富的內部構形結構**：IDS、部件、形旁與聲旁等為字符表示提供了多層次的信息。
- **深厚的文字與文化積累**：漢字文化圈歷代積累的字書、典籍、訓詁、文字學研究及現代數字化資源，都是發展表意文字人工智慧的重要基礎。

這些特點不只是需要被技術「兼容」的差異，而是值得直接轉化為技術優勢的寶貴資源。

**漢字文化圈表意文字的信息處理與人工智慧，應當建立在自身文字體系的特點之上，而不是永遠追隨主要為其他文字系統設計的技術路線。**

## 項目方向

本項目致力於建設以漢字文化圈表意文字為中心的信息處理與人工智慧技術體系，涵蓋但不限於以下領域：

### 1. 表意文字字符與詞表（Characters & Vocabulary）

建立覆蓋 Unicode CJK、康熙部首及漢字文化圈相關表意文字的字符資源與詞表體系，為表意文字中心的人工智慧模型提供統一的字符基礎。

### 2. 表意文字分詞與 Tokenization

研究以表意字符為基礎的 Tokenization 方法，保留字符作為語素及語義錨點的作用，建立符合漢字文化圈表意文字特點的文本表示方式。

### 3. 表意文字描述序列與構形分析（IDS & Character Structure）

收集、整理和利用表意文字描述序列、部件及構形信息，建立字符與其內部結構之間的系統化關聯。

### 4. 表意文字嵌入向量（Ideograph Embeddings）

研究融合字符語義、字形結構、部件關係及上下文信息的嵌入表示，使字符之間的語義與構形關聯能夠直接反映在模型表示中。

### 5. 表意文字中心的人工智慧模型（Ideograph-Centered AI Models）

探索從詞表、Tokenizer、Embedding 到模型架構、訓練方法的完整技術路線，構建真正以漢字文化圈表意文字為中心的人工智慧模型。

## 我們的願景

漢字文化圈表意文字不僅是一套文字編碼系統，更承載著跨越數千年的知識、思想、歷史與文化。

從古代典籍到現代文獻，從漢字到字喃、方塊壯字等衍生文字，這些文字共同構成了一個龐大而深厚的文字文化世界。

信息處理與人工智慧技術的發展，不應使這套文字體系被迫削足適履，適應主要為其他文字系統建立的技術範式。

相反，我們應當充分認識並發揮漢字文化圈表意文字自身的優勢，使其文字結構、語義傳統與文化積累成為新一代信息處理與人工智慧技術的重要基礎。

這不僅是一項信息技術與人工智慧工程，也是一項關乎文字文化傳承、知識表示方式與技術發展方向的長期事業。

**我們不僅要讓人工智慧能夠處理漢字文化圈表意文字，更要讓漢字文化圈表意文字自身的特點參與塑造人工智慧。**

為此，發起 **Unified Sinosphere Ideograph Information Processing and Artificial Intelligence（統一漢字文化圈表意文字信息處理與人工智慧）** 項目。

**以字為本，以形載義，立足漢字文化圈表意文字自身，建立屬於這一文字體系的信息處理與人工智慧技術。**
