# 🈶 基礎常用漢字文化圈表意文字字表

## Motivation

對於生僻漢字、字喃、方塊壯字等表意文字，我們可以利用表意文字描述序列（Ideographic Description Sequence，IDS）對其進行結構分解，幫助人工智慧模型更好地理解和處理這些字符。

我們希望先訓練一個在常用漢字文化圈表意文字上具有優秀表徵能力的模型，再利用 IDS 信息，將模型已經學到的字符知識與表徵能力擴展到生僻漢字、字喃、方塊壯字等其他表意文字。因此，我們需要一份基礎常用漢字文化圈表意文字字表，作為模型學習字符及其內部結構的基礎。

這份字表中的字符應當具有足夠的常用性，以便模型在訓練過程中為其學習到優質的字符嵌入向量（Character Embeddings）。在訓練時，字表內的字符可以採用一字符一 Token 的方式處理，而字表外的字符則通過 IDS 進行分解。這樣，模型既能充分學習常用漢字本身的語義與表徵，又能在字表內外字符共同出現的語境中，學習如何利用 IDS 結構信息表示和理解其他表意文字，從而將常用字符的知識延伸到更廣泛的漢字文化圈表意文字。

此外，這份字表應當兼顧繁體與簡體漢字。由於其他表意文字的 IDS 信息可能同時包含繁體和簡體字形，一個統一、綜合的漢字文化圈表意文字信息處理與人工智慧系統，應當對繁體與簡體漢字提供同等重視和良好支持，而不偏重其中任何一方。

目前仍大規模使用漢字文化圈表意文字的語言主要有漢語（中文）和日語（日文）。為了適應不同的模型訓練需求，我們計劃構建兩份基礎字表：

1. **現代漢語（中文）基礎字表**：面向僅使用漢語（中文）進行訓練的模型。
2. **現代漢語（中文）＋日語（日文）綜合基礎字表**：面向同時使用漢語（中文）和日語（日文）進行訓練的模型。

## 現代漢語繁簡平衡基礎一級字表

**文件：** [`modern_chinese_simplified_traditional_balanced_level_1.txt`](./modern_chinese_simplified_traditional_balanced_level_1.txt)

**字符數量：6,629**

這份字表以中國大陸、臺灣及香港的常用漢字字表為基礎，經過繁簡轉換與合併，構建兼顧繁體和簡體漢字的現代漢語基礎字符集合。

字表來源包括：

- **中國大陸**：《通用規範漢字表》（2013年）一級字，共 3,500 字。
- **臺灣**：《常用國字表》（1982年），提取 4,808 字。
- **香港**：《常用字表》，連同其中列出的異體字，共提取 4,860 字。

對於中國大陸字表，保留原有簡體漢字，並使用 OpenCC 的 `s2t` 轉換取得對應的繁體漢字；對於臺灣和香港字表，保留原有繁體漢字及異體字，並分別使用 OpenCC 的 `tw2s` 和 `hk2s` 轉換取得對應的簡體漢字。

所有轉換均保留一對多映射中的全部候選字符，而不僅限於預設轉換結果。

最後，將中國大陸的繁簡字集、臺灣的繁簡字集及香港的繁簡字集進行並集與去重，得到共 **6,629 個字符**的「現代漢語繁簡平衡基礎一級字表」。

文件採用 UTF-8 編碼，每行一個字符，按照 Unicode Code Point 升序排列，可直接用於構建以字符為基本 Token 單位的人工智慧模型詞表。
